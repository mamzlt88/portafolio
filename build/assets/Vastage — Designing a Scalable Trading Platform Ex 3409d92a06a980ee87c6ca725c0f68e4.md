## 1. Executive Summary

Vastedge is a German company specializing in trading automation systems for financial institutions. Their product, **Varepo**, supports repo transactions, which are essential for short-term liquidity and collateral management in banking.

To secure a partnership with a major European bank, the platform needed to modernize its user experience, improve usability, and adapt to a white-label strategy.

The solution focused on building a **scalable UI system**, redesigning key flows, and aligning the product with the **Velox framework**, enabling faster development and consistent delivery across products.

**Results**

- Improved usability and visual clarity across trading workflows
- Enabled scalability across D2D and D2C products
- Established reusable design foundations for future systems
- Supported successful client acquisition

---

## 2. Discovery: Understanding the Product

Varepo is a platform designed to manage **repo transactions**, a financial mechanism where institutions temporarily sell securities in exchange for liquidity, with an agreement to repurchase them later.

The product serves two main contexts:

- **Dealer-to-Dealer (D2D):** transactions between financial institutions
- **Dealer-to-Customer (D2C):** services provided directly to clients

The system was powerful but complex, with dense data, multiple workflows, and technical terminology that made it difficult to navigate.

The initial discovery revealed a gap between **technical capability and user experience**.

---

## 3. Uncovering the Core Challenge

The platform faced three main challenges:

- **Outdated Interface:** Visual design and interaction patterns did not meet modern standards.
- **Lack of Consistency:** No shared design system, leading to fragmented user experiences.
- **Framework Constraints:** The UI needed to integrate with the **Velox execution engine**, limiting design flexibility.

At the same time, the product needed to impress a high-level banking client.

The challenge was not only to redesign, but to **elevate the product to enterprise-level expectations**.

---

## 4. The Strategy

The approach focused on creating a **scalable and reusable design foundation** while improving usability.

Instead of redesigning isolated screens, the strategy was to:

- Build a **UI Kit and Style Guide** based on atomic design principles
- Align design decisions with the Velox framework
- Improve user flows through collaboration with the Product Owner

The goal was to create a system that could be reused across Vastedge’s products, not just Varepo.

---

## 5. Research and Insights

The initial analysis focused on reviewing existing UI assets, documentation, and workflows.

Key findings included:

- Interfaces lacked visual hierarchy and clarity
- Components were inconsistent or duplicated
- Documentation was outdated or missing
- Users relied heavily on training rather than intuitive navigation

These insights showed that the main issue was not feature complexity, but **lack of structure and guidance**.

---

## 6. Planning the Redesign

To align the redesign, a structured approach was defined:

- Audit existing UI and workflows
- Define reusable components
- Establish a consistent visual language
- Align design with development constraints

The goal was to reduce friction, improve usability, and create a scalable system that could support both D2D and D2C products.

---

## 7. Building the Foundation

A **UI system** was created using atomic design methodology, breaking the interface into:

- Atoms (buttons, inputs, labels)
- Molecules (form groups, controls)
- Organisms (complex components and layouts)

This structure enabled:

- Faster development cycles
- Consistent UI patterns
- Easier scalability across products

The foundation focused on reusability and clarity.

---

## 8. Building the Design Language

A cohesive design language was established to unify the product:

- **Color:** Defined palettes for clarity and hierarchy
- **Typography:** Structured text scales for readability
- **Grid:** Consistent layout system for alignment
- **Components:** Standardized UI elements across flows

This created a visual system that supported both usability and technical constraints.

---

## 9. Designing While Adapting to Velox

One of the main challenges was working within the **Velox framework**, which dictated certain structural and technical limitations.

Instead of resisting those constraints, the design adapted to them:

- Components were designed to fit existing architecture
- Patterns were validated with developers early
- Design decisions balanced usability with feasibility

This collaboration ensured that designs were not only ideal, but also buildable.

---

## 10. Improving the Product

The redesign focused on simplifying key workflows:

- Improved navigation across trading processes
- Reduced cognitive load in data-heavy screens
- Enhanced clarity of transaction states and actions
- Created consistent patterns for user interaction

High-fidelity prototypes were used to validate flows and communicate solutions clearly to stakeholders.

---

## 11. The System in Action

The UI Kit and Style Guide became essential tools for the team:

- Designers used them to maintain consistency
- Developers used them to accelerate implementation
- Product teams used them to align decisions

The system enabled Vastedge to extend the design to other products, improving efficiency beyond the initial scope.

## 13. Reflections

This project highlighted the importance of balancing **design ambition with technical reality**.

Working within the Velox framework required flexibility and collaboration, showing that good design is not only about creativity but also about adaptability.

The introduction of a UI system shifted the team from reactive design work to a more structured and scalable approach.

---

## 14. Lessons Learned

1. **Structure simplifies complexity**
Breaking down systems into reusable components makes complex products manageable.
2. **Constraints drive better solutions**
Working within a framework forces clarity and focus.
3. **Consistency improves confidence**
Users trust systems that behave predictably.
4. **Design systems create long-term value**
They extend beyond a single product and enable future growth.
